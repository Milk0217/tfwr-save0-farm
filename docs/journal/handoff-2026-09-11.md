## 接手要做的三件事（按优先级）

1. **确认仙人掌补课线的去留**（阻塞其它判断）
   重启 `main.py`，看首行 `[main] BUILD 40`，然后取这一行的**真实数字**：
   `[cactus] WARNING: mazes cost <值> exceeds cap <上限> -> capped`
   —— BUILD 40 新加的告警，因为此前 `need` 正好等于上限 ⇒ 真实成本未知。
   **判据**：真实成本 ≲ 500 万 ⇒ 继续补课（迷宫金币再翻倍）；≫ 500 万 ⇒
   把 `CACTUS_PUSH_ENABLED = 0`，把地还给南瓜、专心跑 `maze_gold.py` 攒金币升 Megafarm。

2. **仙人掌并行改成 32 个矩形**（吞吐约 1.7 倍）
   依据与实现要点见 `docs/plans/cactus-parallel.md` 的**补充分析**（写在会话里，尚未落盘，要点重述）：
   - 产量 = `4n²`（n = 一块连通区的格数，实测 6×6 → 5,184）；区域产量和 = `4Σnᵢ²`（凸）、
     排序耗时 ∝ `n^1.5` ⇒ **吞吐 ∝ √(区域数)** ⇒ 用满 32 块比 14 块快约 1.7 倍；
   - 地块：14 方阵（504）+ 胡萝卜带（128）+ 木草带（48，需先 `till`）= **680 格 ÷ 32 ≈ 每块 21 格**；
   - 改法：`CACTUS_CFG` 从「方阵下标」改为 **`[ox, oy, w, h]`**，`cactus_x` 与 6 处行坐标全部带原点、
     循环边界改成 `w`/`h`；`spawn_drone` 把 `(ox,oy,w,h)` 当参数传（跨机只走参数）。
   - **必须**：改完跑方阵/矩形互不重叠自检（两块相邻会被 `swap` 互踩 ⇒ `violations` 不为 0）。

3. **模块化剩余两步**（依据 `docs/plans/modularize-main.md`，第 0 步实验可跳过 —— import 语义已由
   `docs/scripting/import.md` 确认）
   - 删死代码：`main4` / `run_one_sweep4` / `work_left` / `work_right` / `game_loop` /
     `tend_sunflowers` / 旧 `work_pumpkin`（它**只数第 0 号方阵**，是必须清掉的陷阱）；
   - 再抽 `w_carrot.py` / `w_sun.py` / `w_cactus.py`（照 `w_pumpkin.py` 的自包含模式：
     自己带 `goto` / `water_if_needed` / 状态表 / 版本号）。

## 操作纪律（违反必出事，详见 lessons 文档第一节）

- 改脚本**只用 `edit`/`write` 工具或 Python（显式 UTF-8 + `newline="\n"`）**，**绝不 PowerShell 往返**；
- 改前**重读文件**（游戏每跑完一次会回写 `.py`）；
- 改完**三连验证**：`py_compile` → `python tools/audit_save0.py` →（几何改动）间距/下标自检；
- **补丁先核对锚点命中数再写文件**，命中数不对就 ABORT；
- 每次改动带**版本号自增**并打印，否则无法确认游戏跑的是哪一版。
