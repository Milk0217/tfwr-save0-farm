## 已经跑通的链路（v10 = 当前版本）

一块地 → 11~25 分钟依次拿到：`Speed → Expand → Plant → Carrots → Watering → Trees
→ Fertilizer → Pumpkins → (Sunflowers 在望)`，世界 1×1 长到 6×6 ✓

三格轮作 `(x + 2y) % 3`：0 种灌木(wood) / 1 种胡萝卜(carrot) / 2 留草(hay)；
**攒 Expand 的钱时切"原地割草"模式**（1.26/秒 vs 轮作里 0.26/秒）—— 这一手解决了 v7 世界卡死 3×3 的问题。

## 血泪纪律（这轮连栽四次，务必遵守）

* **调用任何动词前先问它解锁了没**：`plant(Carrot)` 要 Carrots、`plant(Tree)` 要 Trees、
  `use_item(Fertilizer)` 要 Fertilizer。v3/v4/v5 三次崩溃全是这一类。
* **阶段开关不能依赖于该阶段要产出的东西**：v4 把"转入木材段"设成 `Unlocks.Carrots`，
  而 Carrots 要 wood=50 ⇒ "没 wood 就不产 wood" 自锁 15 分钟 ✗
* **不要用 PowerShell 的 `Get-Content | Set-Content` 改脚本**：会把 UTF-8 中文整片搞成乱码
  还吃掉引号（本轮真栽过）。改代码一律用 patch 脚本 + 锚点断言，或 edit 工具。
