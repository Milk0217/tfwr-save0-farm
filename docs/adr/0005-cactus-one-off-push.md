# 仙人掌不占永久功能带，只做一次性补课

## Status

accepted —— 但**「触发条件 = 恐龙解锁的 2000 个」和成本数字已被 [ADR 0007](0007-cactus-target-selection.md) 取代**（2026-09-12，BUILD 41）。
仍然成立的部分：**仙人掌不占永久功能带、临时征用已耕好的地、跑完自动种回去**。

## 背景与决策

仙人掌的产量规则是「一次收获 n 株 → 得 n² 个」，而 s×s 方阵里 n = s²，所以一次收获 `s⁴` 个、**每格 `s²` 个**。6×6 一次就是 **1296** 个，每格 36 —— 比巨型南瓜（封顶 6/格）高一个数量级。这看起来像是最该长期占地的作物。

但它不占。**因为它的唯一消耗者是 `Unlocks.Dinosaurs`，要 2000 个，之后没有任何下游。** 一个 6×6 方阵两轮就能凑够，代价仅为分钟级的无人机时间。开一条永久仙人掌带等于白占 36 格。

执行方式是**临时征用 PUMPKIN 带**：它本来就是耕好的 6×6 正方形，连 `till()` 都不用；跑完主循环会自动把南瓜种回去。触发条件完全由状态驱动 —— `num_items(Items.Cactus) < get_cost(Unlocks.Dinosaurs)`，恐龙一解锁，补课自动停止。

## Considered Options

- **永久仙人掌带（6×6）**：与南瓜争夺右半区。但南瓜是 `Expand` 的唯一货币（下一级 64000），而仙人掌凑够 2000 就再无用途。
- **从左半区切 6×6（WOOD 3 行 + HAY 3 行）**：几何可行，但 HAY 会从 24 格掉到 6 格，而干草是胡萝卜的耗材（8/株）。
- **暂不做，等扩张后再开**：拖延没有收益 —— 恐龙的 2000 个仙人掌是当前进度上的一段硬门槛。

## Consequences

- 补课期间南瓜停止产出，时长约 2 分钟（两轮），对 64000 的扩张目标影响可忽略。
- 种 1 株仙人掌耗 **2 南瓜**，一轮 36 株 = 72 南瓜；因此补课前有 `CACTUS_PUMPKIN_RESERVE = 300` 的门控，南瓜不足时让位给主循环去攒。
- 排序只能靠 `swap()` 做相邻交换，且每次补种都重新随机尺寸，成本每周期重付。用局部修复循环，并以势能 `P = Σ 尺寸 × (x + y)` 保证终止。
- `CACTUS_MAX_CYCLES = 12` 是防死循环的硬上限；`cactus_plant_and_wait` 里还有「南瓜被抽干就立刻退出」的保险。
